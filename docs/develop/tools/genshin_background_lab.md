# 原神后台验证工具开发说明

工具位于 `tools/genshin_background_lab/`，与 `src/zzz_od/` 的绝区零业务实现隔离。它只验证非侵入式 Windows 截图与输入接口，不作为一条龙应用注册，也不复用游戏自动化流程。

截图实现统一返回图像、时间戳、耗时和错误；输入实现统一提供安全单次动作和全部释放。窗口筛选同时使用进程、可执行文件、窗口类名和标题。纯计算和状态切换逻辑由独立测试仓覆盖，真实原神、不同窗口状态、XInput/DS4 轮询及前台程序影响保留为人工测试。

当前版本是实验骨架。Windows Graphics Capture 连续会话、完整资源统计面板和四种状态的真实结论未完成时必须明确显示为待验证，不得依据 API 返回值填写通过。
