# 原神后台截图与输入验证实验室

这是一个与绝区零业务代码隔离的 Windows 实验工具，用于测量原神窗口在不同状态下的截图和输入表现。它默认只调用公开的系统接口，不注入进程、不读写游戏内存、不加载 DLL、不安装内核钩子，也不尝试隐藏自动化行为。

> 使用前请自行确认原神服务条款和反作弊规则。即使接口来自 Windows，自动输入仍可能违反游戏规则。本工具不能保证账号安全。

## 安装和启动

要求 Windows 10 1903 或更高版本、Python 3.11、[uv](https://docs.astral.sh/uv/)。在 PowerShell 中执行：

```powershell
cd tools/genshin_background_lab
.\start.ps1
```

脚本会建立隔离环境并安装 PySide6、MSS、`windows-capture` 和 `vgamepad`。虚拟手柄还需要已安装的 ViGEmBus 驱动；“包能导入”不代表驱动可用，启动诊断会实际创建并释放一次 Xbox 360 测试设备。虚拟 HID 需要另行准备合规的签名驱动，本工具不会安装或提供内核驱动。

## 选择原神窗口

1. 启动原神并进入可安全观察的菜单。
2. 点击“刷新窗口”。工具同时核对进程 ID、`GenshinImpact.exe`/`YuanShen.exe`、`UnityWndClass` 和窗口标题；不会只按标题匹配。
3. 核对界面中的客户区尺寸、DPI、前台状态、最小化状态和句柄重建提示。遮挡状态无法只靠窗口属性可靠判断，因此要求人工确认。

## 截图测试

可选后端包括 Windows Graphics Capture、PrintWindow、BitBlt 和 MSS 桌面截取。每帧记录时间戳、耗时和错误，并在 API 报告成功之后继续检测黑帧、重复帧、固定旧帧和尺寸变化。当前 WGC 入口会先验证依赖，但连续捕获会话尚未完成，因此会明确报错，不能作为已验证结论。

对每个后端分别执行以下状态，状态切换后至少观察 30 秒：

1. 原神在前台；
2. 原神被其他窗口完全或部分遮挡；
3. 原神在后台但客户区可见；
4. 原神最小化。

记录平均耗时、P50/P95、有效帧率、进程 CPU、内存变化和有效帧比例。当前界面提供实时帧数、单帧耗时、平均耗时和失败数；完整状态统计仍需在导出报告中人工补录，不能把未采集字段当作通过。

预览只使用当前选择的后端。后端失效时默认停止预览并显示错误，不会静默换成桌面截图。用户可明确勾选自动回退；启用后日志会记录原后端、错误和切换目标，界面始终显示实际后端。

## 输入测试

输入后端分为：

- 窗口键盘/鼠标消息，包括完整客户区坐标编码和连续 `WM_MOUSEMOVE` 拖拽；
- SendInput；
- vgamepad Xbox 360；
- vgamepad DS4；
- 用户自行准备的虚拟 HID 条件方案。

SendInput 和系统虚拟手柄是**系统级输入**，不天然绑定所选窗口。`PostMessage` 返回成功只表示消息进入窗口消息队列，不表示游戏采用了输入。Raw Input、DirectInput、XInput 或 DS4 是否生效，必须通过画面变化或人工观察确认。

每次只在菜单中测试方向、确认/取消、短促摇杆偏转或单次按钮。点击测试按钮后有 3 秒倒计时；紧急情况点击“立即停止”，工具会释放所有按键、按钮、扳机和摇杆，正常退出时也会再次释放。不要在战斗、联机、聊天框或可能造成消费的页面测试。

### 失去焦点的手柄专项检查

1. 保持原神前台，短按虚拟手柄按钮，确认菜单有且仅有一次变化。
2. 切到记事本等无破坏性的程序，再次短按，观察原神是否仍轮询 XInput/DS4、是否暂停手柄读取。
3. 同时观察当前前台程序是否误收虚拟手柄输入。
4. 报告必须分别填写“目标游戏收到输入”“前台程序未受影响”；无法从画面确认时填写“无法自动确认，需要人工观察”，不得用驱动调用成功代替。

## 报告与结果判断

点击“导出 JSON/CSV 报告”，默认放在工具目录的 `reports/`。保存以下环境信息：Windows 完整版本、原神显示模式、客户区分辨率、游戏帧率限制、GPU、DPI、权限等级和测试时间。有效后端必须在目标状态下持续产生非黑、非固定旧帧且尺寸正确的画面；一次 API 成功或一张偶然正确截图均不算通过。

真实原神验证是人工测试，不是单元测试。提交结论前应保存四种状态的结果和观察说明。

## 已知限制

- 本仓当前执行环境不是 Windows，不能代替真实游戏完成四种窗口状态和虚拟手柄人工验证。
- WGC 连续捕获会话、完整 P50/P95/CPU/内存面板和自动画面变化判定仍待完成；界面会明确显示缺失，不会伪造通过。
- 遮挡判断与“前台程序未受影响”无法普遍自动化，需要人工观察。
- PrintWindow、BitBlt 和桌面截取的行为取决于 Windows 版本、显卡驱动、全屏模式和游戏渲染路径。
